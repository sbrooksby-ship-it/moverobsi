**Simple Summary**

- **Deductive** = Guarantee (General rule $\rightarrow$ Specific fact)
    
- **Inductive** = Probability (Observed patterns $\rightarrow$ Best guess)
    
- **Valid** = Solid structure (Facts can still be fake)
    
- **Sound** = Solid structure + True facts

**Deductive** goes from broad rule to specific guarantee, if premises are true than the conclusion has to be true. 
For example all Iphones run ios. You have an Iphone. Therefore your phone runs ios.

**Inductive** looks at past evidence to guess what is probably true. 
For example every time I order tacos from this food truck they're great. I assume today's order will be great too.

**Core Structure & Mechanics**
* **Rule / Mechanism:** 
  * **Deductive:** Top-down (General rules $\rightarrow$ Specific certainty).
  * **Inductive:** Bottom-up (Specific observations $\rightarrow$ General probability).
* **Formal Notation (Deductive Valid Form):** 
  $$\begin{aligned}
  P_1 &: A \implies B \\
  P_2 &: A \\
  \therefore C &: B
  \end{aligned}$$
* **Classic Example (Deductive):** All humans are mortal ($P_1$). Socrates is human ($P_2$). Therefore, Socrates is mortal ($C$).
* **Classic Example (Inductive):** Every raven observed so far is black ($P_1$). Therefore, all ravens are black ($C$).

**Common Misconceptions**
* Inductive reasoning is not "flawed" just because it lacks absolute certainty—it is meant to measure probability, not absolute proof.
* A deductive argument can be structurally perfect (valid) even if its premises are completely false in reality (unsound).
